# 하이웨이 드라이버

> 무사고로 열심히 달려왔는데 집에서 10분거리에서 사고나서 빡쳐서 만든 게임

운과 선택으로 고속도로를 달려 집까지 가는 브라우저 게임. 설치 없이 바로 플레이할 수 있다.

**플레이:** https://kone3765.github.io/highway-driver/

## 어떻게 노는가

- 재력 · 행운 · 운전실력 세 스탯에 총 18점까지 나눠 담는다. 다 안 써도 출발은 된다.
- 코스가 난이도다. 세종포천(★1)부터 경부(★5)까지, 실제 고속도로와 실제 제한속도.
- 100 / 110 / 120 / 130km/h 중 고르며 달린다. 빠를수록 빨리 도착하지만 사고·단속 위험도 같이 오른다.
- 단속 카메라는 운과 상관없이 매 구간 나온다. 터널, 다중 추돌, 앞차 비상등(5초 안에 브레이크 + 비상등), 친구 전화, 휴게소…
- 여비가 0원이 되면 파산, 차가 다 부서지면 폐차. 목적지에 도착하면 걸린 시간으로 S~D 랭크.
- 업적 27개(숨겨진 업적 6개). 기록은 브라우저에만 저장된다.

## 파일

- `index.html` — 게임 전체 (단일 파일, 서버 불필요)
- `_build/sim-harness.js` — 난이도 측정용 봇. 로컬에서 페이지에 주입해 쓰는 개발 도구라 게임에는 들어가지 않는다
